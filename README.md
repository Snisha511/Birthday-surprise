# A Surprise Just for Surya

A mobile-friendly birthday surprise website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. If you have Node.js installed, run `npm install` only if you add a development server later. No build step is required for this version.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish it so anyone can open it
The easiest free option is Netlify Drop:
1. Open https://app.netlify.com/drop
2. Drag the extracted `surya-birthday-surprise` folder onto the page (or zip the three site files and upload them, depending on the current page instructions).
3. Netlify will provide a public HTTPS link you can send to Surya. Keep the published site online for the link to work.

Alternative: create a GitHub repository and deploy the files using GitHub Pages.

## Personalize
- The displayed name is set to `Surya` in `script.js` and also appears as fallback text in `index.html`.
- The letter and balloon messages are easy to edit in `index.html`.
- Google Fonts require an internet connection; the page still works with fallback fonts if they are unavailable.
